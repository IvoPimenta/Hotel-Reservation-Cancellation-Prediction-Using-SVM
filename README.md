# 🏨 Hotel Reservation Cancellation Prediction (SVM Classifier)

Machine Learning project for predicting online hotel reservation cancellations using Support Vector Machines.

🤖 Project Description
The goal of this project is to develop a predictive machine learning model capable of forecasting hotel reservation cancellations based on historical reservation data. The dataset contains guest and booking features, and the solution was implemented using Python and Scikit-learn with a focus on optimizing the F1-score.

This work addresses a real-world business problem and helps hospitality companies minimize losses due to unexpected cancellations, enabling better planning and resource management.

🚀 Features
Data preprocessing and exploratory data analysis (EDA)

Implementation of SVM classifier with hyperparameter tuning

Handling of imbalanced classes and feature engineering

Model evaluation using accuracy, precision, recall, and F1-score

Classification of new, unlabeled reservations

Outputs predictions in required CSV format for operational use

🛠️ Tech Stack
Python 3

Scikit-learn

Pandas

NumPy

Matplotlib / Seaborn (EDA)

Jupyter Notebook

🌟 Highlights

High-performance classification model tailored for imbalanced datasets

Clean and modular implementation following ML best practices

Real-world use case with direct impact on business decision-making

Project includes notebook, predictions CSV, and professional slide presentation
